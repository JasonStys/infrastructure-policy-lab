# Security reporting

Created by Jason Stys. Report issues privately through [LinkedIn](https://www.linkedin.com/in/jason-stys-31b30b351/) or ask how to arrange a private report; do not publish credentials, account state, private infrastructure names or exploit payloads from real systems.

This educational offline lab is not a production authorization/compliance platform. Read the threat model and limits before using real plans. No cloud account, privilege grant, paid resource, enforcement, data deletion or host security change is performed by its CLI or validation. Source changes and third-party tool updates require fresh review/tests. Author self-review and scans do not guarantee absence of unknown vulnerabilities.
